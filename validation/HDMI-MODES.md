# S905X2 / CoreELEC NO 模式验证

环境：22.0-Piers_nightly_20261007、5.15.196、G12A u212 2GB；经 DENON 功放连接电视。

原 500MHz 阶段：用户确认 24/25Hz 正常、继续提高后花屏；4K60 4:2:0 / 8bit（TMDS 297MHz）仍异常，而同模式硬件 BIST 彩条正常。保持 HDMI 模式不变、仅将 VPU 改至 666.7MHz 后 Kodi 恢复。没有完成原故障下全部格式的逐项目视记录，不能补写为全部失败。

低速模式 CED 锁定字段会显示 unlocked，且切换时会短暂失锁；不据此否定用户确认的正常画面。NO compat_mode 会忽略 modetest 色彩 property，表内格式均以 hdmitx config 和 format_para 实际回读为准。
